Engineering Excellence

Built for Modern DevOps

Local SQLite Persistence

The desktop edition stores all data directly in %APPDATA%\GITE_NV\gite_nv.db. Your data is 100% durable and never deleted during updates or cache wipes.

Default-to-Secret Masking

Security by default. All parsed environment variables and credentials automatically default to write-only encrypted secrets, eliminating accidental exposure.

Dual-Scope Deploy Keys

Choose between Per-Repo Deploy Keys (isolated access for a single repo) or Account SSH Keys (registered once on your GitHub account to access all repos).

Smart Import & Auto-Detect

Paste raw text, .env files, multiline private keys, or VPS script outputs. GITE_NV auto-parses, categorizes, and formats every entry in real time.
