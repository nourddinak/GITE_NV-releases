ENGINEERING EXCELLENCE

Built for Modern DevOps & Full-Stack Developers

Stop re-typing API tokens, database connection strings, and SSH keys for every repo. Profile once, deploy anywhere.

Local SQLite Persistence

The desktop edition stores all data directly in %APPDATA%\GITE_NV\gite_nv.db using embedded SQLite. Your data is 100% durable and never deleted during updates or cache wipes.

Default-to-Secret Masking

Security by default. All parsed environment variables and credentials automatically default to write-only encrypted secrets, eliminating accidental exposure in public repository logs.

Dual-Scope Deploy Keys

Choose between Per-Repo Deploy Keys (isolated access for a single repo) or Account SSH Keys (registered once on your GitHub account to access all repos).

Smart Import & Auto-Detect

Paste raw text, .env files, multiline RSA/ED25519 private keys, or VPS script outputs. GITE_NV auto-parses, categorizes, and formats every entry in real time.

Multi-Environment Profiles

Manage isolated profiles for Production, Staging, and Preview environments with distinct tokens, ports, and domains. Deploy all variables with a single click.

Encrypted Backup & Portability

Export all profile definitions to client-side password-encrypted JSON backups using libsodium. Seamlessly migrate between the Extension and Desktop App in seconds.

COMMON INQUIRIES

Frequently Asked Questions

Where is my data stored in the Windows Desktop App?
Your data is stored in a native ACID-compliant SQLite database file located at %APPDATA%\GITE_NV\gite_nv.db. It lives completely on your local computer and is never wiped during updates or uninstallations.
How do I migrate my profiles from the Extension to the Desktop App?
In the extension, open Settings and click Export Encrypted Backup. Set a passphrase and save the JSON file. Then, open the Desktop App, click Import & Merge, enter your passphrase, and your profiles, deploy keys, and tokens are instantly imported.
What does the VPS Auto-Discovery script do?
The command bash <(curl -fsSL https://raw.githubusercontent.com/nourddinak/SCRIPTS/main/setup-github.sh) executes a safe read-only discovery script on your Linux server. It detects your public IP, username, and SSH setup, creates an isolated deployment key, and prints out key-value pairs formatted specifically for GITE_NV's smart parser.
Does GITE_NV send my credentials or tokens to any external server?
No. GITE_NV communicates exclusively with the official GitHub REST API (api.github.com) using your personal token. There is zero telemetry, no tracking server, and no third-party cloud database.
